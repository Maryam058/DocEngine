# Terminology Glossary

This glossary defines common terms used in software documentation and technical writing for DocEngine.

| Term | Definition | Example | Related Terms |
| --- | --- | --- | --- |
| API | A set of protocols and tools for building and interacting with software services. | "Use the API to retrieve account data." | Endpoint, Request, Response |
| Authentication | The process of verifying a user's identity before granting access. | "Authenticate with an API key." | Authorization, Login |
| Authorization | The process of granting access to specific resources or actions. | "The token authorizes read-only access." | Authentication, Permissions |
| Backend | The server-side logic and infrastructure that powers an application. | "The backend processes incoming requests." | Frontend, Server |
| CLI | A command-line interface used to run commands and scripts. | "Run the CLI command to deploy the app." | Terminal, Shell |
| Code Block | A section of text formatted to display source code clearly. | "Use a fenced code block for shell commands." | Syntax Highlighting, Markdown |
| Configuration | Settings that define how an application or service behaves. | "Update the configuration file to change the port." | Environment, Settings |
| Dependency | A package or module required by software to function correctly. | "The project has a dependency on Flask." | Package, Library |
| Deployment | The process of making an application available to users. | "Deployment to production occurred at midnight." | Release, Production |
| Documentation | Written information that explains how something works or how to use it. | "The documentation includes setup steps." | Guide, Reference |
| Endpoint | A specific URL or route exposed by an API. | "The endpoint returns user profile data." | API, Route |
| Environment | A runtime context such as development, staging, or production. | "Use the staging environment for testing." | Configuration, Deployment |
| Error Message | A notification that explains a problem or failure. | "The error message says the token is expired." | Exception, Warning |
| Example | A sample showing how something should be done or appear. | "The example illustrates a successful request." | Tutorial, Snippet |
| Feature | A distinct capability or function provided by software. | "The feature allows exporting reports." | Capability, Functionality |
| Frontend | The user-facing part of an application. | "The frontend displays the dashboard." | Backend, UI |
| Git | A version control system used to track changes in source code. | "Commit the change with Git." | Repository, Branch |
| Guide | A document that helps the reader perform a task. | "Follow the guide to install the tool." | Tutorial, Documentation |
| Header | Metadata or additional information placed at the top of a document or request. | "The header contains the authorization token." | Metadata, Request |
| Input | Data provided to a system or function. | "The input field accepts an email address." | Output, Parameter |
| Installation | The process of setting up software on a machine or environment. | "Installation completed successfully." | Setup, Configuration |
| Integration | The process of connecting systems or services so they work together. | "The integration syncs the CRM with the app." | Connector, API |
| Issue | A problem, bug, or task that needs attention. | "The issue was reported by a customer." | Bug, Ticket |
| Library | A reusable collection of code or functionality. | "The library provides charting tools." | Package, Dependency |
| Markdown | A lightweight markup language used to format text. | "Write the page in Markdown." | Formatting, Plain Text |
| Metadata | Descriptive information about a file, page, or record. | "The metadata includes the author name." | Header, Tag |
| Navigation | The structure that helps users move through content. | "Navigation links lead to the setup page." | Menu, Sidebar |
| Parameter | A named input used by a function, command, or API call. | "The parameter sets the page size." | Argument, Input |
| Permissions | The rights granted to users or services for specific actions. | "Permissions control who can edit content." | Authorization, Role |
| Pipeline | A sequence of automated steps used to build, test, or deploy software. | "The pipeline runs tests after each commit." | CI/CD, Workflow |
| Preview | A temporary view of content before publication. | "Preview the page before publishing it." | Draft, Local Server |
| Release | A version of software made available to users. | "The release includes bug fixes and improvements." | Deployment, Version |
| Repository | A storage location for code or documentation files. | "The repository contains the project source." | Git, Branch |
| Request | A message sent to a service or API to perform an action. | "The request returned a 200 status code." | Response, Endpoint |
| Response | The data or status returned after processing a request. | "The response contains the created resource." | Request, Payload |
| Route | A defined path that maps a URL to application logic. | "The route handles user profile requests." | Endpoint, Path |
| Screenshot | An image capture of a screen or interface. | "The screenshot shows the dashboard view." | Image, UI |
| Search Index | A structured collection of content used to make search fast and accurate. | "The search index updates when content changes." | Search, Indexing |
| Server | A system that hosts applications or services. | "The server responds to client requests." | Backend, Host |
| Session | A temporary interaction period between a user and an application. | "The session expires after inactivity." | Token, Login |
| Snippet | A small reusable example or fragment of code or text. | "Use the snippet in the example section." | Example, Template |
| Syntax Highlighting | Formatting that visually distinguishes code elements. | "Syntax highlighting improves readability." | Code Block, Markdown |
| Template | A reusable structure for creating consistent content. | "The template defines the page layout." | Snippet, Framework |
| Terminal | A text-based interface for running commands. | "Open the terminal and run the command." | CLI, Shell |
| Token | A credential or identifier used to authenticate access. | "The token is passed in the authorization header." | Authentication, Session |
| UI | The visual interface through which users interact with software. | "The UI includes a sidebar and a toolbar." | Frontend, UX |
| UX | The overall experience a user has while interacting with a product. | "The UX is designed to minimize friction." | UI, Usability |
| Version | A specific release or iteration of software. | "Version 2.0 introduces a new dashboard." | Release, Update |
| Workflow | A sequence of steps used to complete a task or process. | "The workflow includes review and approval." | Process, Pipeline |
