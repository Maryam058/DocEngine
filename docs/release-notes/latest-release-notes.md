# Latest Release Notes

## Overview

This release includes usability-focused enhancements to reporting and referral workflows to make day-to-day operations more efficient.

## Improvements

- **AUS-534** - Added filter options to the Service Analysis Report for both invoice date and appointment/seen date.
- **AUS-525** - Improved referral creation by allowing referrals to be accepted or declined directly on the creation screen.
- **AUS-271** - Improved the referral queue experience for ACC claim processing.
