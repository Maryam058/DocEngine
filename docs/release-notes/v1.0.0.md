# Release Notes

## Version 1.0.0
**Release Date:** 30 July 2026

---

## Overview

Version 1.0.0 introduces the first public release of the DocEngine documentation platform. This release includes user guides, API documentation, release notes, glossary, and an AI-assisted documentation workflow with human review.

---

## New Features

### Documentation Portal

- Published documentation using MkDocs Material.
- Responsive navigation and search.
- Consistent page layout across all documentation.

### AI-Assisted Authoring

Introduced an AI-assisted documentation workflow that includes:

- AI-generated draft creation.
- Human editor review.
- Live preview.
- Edit history tracking.
- Difference summary.
- Publication workflow.

---

## Improvements

- Improved page navigation.
- Standardized headings and formatting.
- Updated terminology for consistency.
- Enhanced readability across all documentation pages.
- Optimized documentation structure for easier maintenance.

---

## Fixed Issues

- Fixed navigation inconsistencies.
- Corrected formatting issues in user guides.
- Improved image rendering.
- Resolved broken internal documentation links.
- Fixed layout issues on smaller screens.

---

## Known Limitations

- AI authoring workflow is intended for documentation review only.
- Draft review data is currently stored locally in the browser.
- Markdown comparison provides a basic line-by-line summary.
