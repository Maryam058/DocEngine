# Password Reset Guide

## Introduction
This guide explains how to securely reset a user password in DocEngine environments.
It is intended for support staff and internal users who need a reliable, repeatable process.

## Prerequisites
- Access to the DocEngine login page.
- A valid user account that is registered in the system.
- Access to the email inbox associated with that account.
- A secure device and network connection.

## Step-by-Step Instructions
1. Open the DocEngine sign-in page.
2. Select **Forgot Password**.
3. Enter your registered email address and submit the request.
4. Open the password reset email and select the reset link.
5. Enter a new password that meets policy requirements.
6. Confirm the new password and submit.
7. Return to the sign-in page and log in with the updated password.

## Notes
- Password reset links are time-limited and can only be used once.
- If the email does not appear, check the spam or junk folder.
- If multiple reset requests are submitted, use the most recent email link.

## Warning
- Never share reset links or one-time tokens with other users.
- Do not reset passwords on untrusted or public computers.
- If unexpected reset emails are received, report the event to security immediately.

## FAQ
### Why did my reset link expire?
Reset links expire for security reasons. Submit a new reset request and use it promptly.

### I did not receive a reset email. What should I do?
Verify the entered email address, check spam folders, and wait a few minutes before requesting again.

### Can I reuse an old password?
In most environments, password history rules prevent reusing recent passwords. Choose a new unique password.
