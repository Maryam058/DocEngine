# Release Notes

## Overview

This release includes improvements to service analysis reporting and referral workflows.

## Improvements

### Reporting

- **Service Analysis Report date filters** — Added filter options for both invoice date and seen/appointment date in the Service Analysis Report.
  - Ticket: `AUS-534`

### Referral workflows

- **Referral acceptance at creation** — Added accept and decline options when creating a referral.
  - Ticket: `AUS-525`

- **Referral queue ACC claim workflow** — Improved ACC claim handling in the referral queue.
  - Ticket: `AUS-271`

## Summary

The release improves report filtering and streamlines referral and ACC claim workflows.
