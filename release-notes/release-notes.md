# Release Notes

## Overview

This release improves service analysis reporting and referral workflows.

## Improvements

### Reporting

- **Service Analysis Report date filters** — Added filters for invoice date and seen/appointment date.
  - Ticket: `AUS-534`

### Referral workflows

- **Referral acceptance during creation** — Added Accept and Decline options when creating a referral.
  - Ticket: `AUS-525`

- **Referral queue ACC claim workflow** — Improved ACC claim handling in the referral queue.
  - Ticket: `AUS-271`

## Summary

The release adds date filtering to the Service Analysis Report and improves referral acceptance and ACC claim workflows.
